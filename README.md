# QCM GROUPE VICRA — Prototype initial

Ce dépôt contient un prototype statique de QCM pour démontrer le parcours stagiaire.

## Démarrage
Ouvrir `index.html` dans un navigateur, ou publier le dossier sur Netlify.

## Limites importantes
- Aucun compte administrateur ou stagiaire n'est encore créé.
- Aucun résultat n'est enregistré.
- Les questions sont uniquement des exemples pédagogiques et doivent être validées.
- Ne pas saisir de données personnelles réelles dans ce prototype.

## Suite du développement
Ajouter une application structurée, l'authentification et la base de données Supabase avec règles d'accès, puis l'administration des questions et le suivi des résultats.
